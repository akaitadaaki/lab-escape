# LAB ESCAPE - 閉鎖された研究所

ブラウザで遊ぶ3D脱出ゲーム。部屋を調べ、研究員と警備ロボットに話を聞き、3つの謎を解いて数字札を集め、出口の3桁コードを入力して脱出する。制限時間は10分。

## 動かし方

```bash
npm install
npm run dev
```

- `npm test` … ロジックと謎プールのテスト
- `npm run build` … `dist/` に静的ファイルを出力（相対パスなので GitHub Pages などのサブパス配下にも置ける）
- URLに `?seed=123` を付けると、同じ謎の組み合わせを再現できる（シードは画面左下に表示）

## 構成

| 場所 | 内容 |
|---|---|
| `src/puzzle/pool.ts` | 謎プール（AIが事前生成 → 人が検品するデータ） |
| `src/puzzle/combine.ts` | シードから、型とスロットが衝突しない3問を選び、数字札と出口コードを割り当てる |
| `src/puzzle/answer.ts` | 答えの判定 |
| `src/game/game.ts` | ゲーム状態（タイマー・メモ・持ち物・誤答ロック・救済ヒント・出口） |
| `src/scene/` | Three.js の部屋と操作 |
| `src/ui/` | HTMLオーバーレイのUI |

## 謎を追加するとき

1. `src/puzzle/pool.ts` に `PuzzleDef` を追加する。型は `dial` / `sequence` / `item` / `testimony` / `cipher` の5種類。
2. `npm test` を実行する。`pool.test.ts` が、答えの形式・スロットの重複・全シードで組み立て可能かを検証する。
3. 本棚の本の冊数、絵の構図、薬品棚の瓶の量は `src/scene/room.ts` の3D表示と文章を一致させている。これらに触れる謎は表示と矛盾しないようにする。

1つの謎が占有できる「物」は3つまで。人物（研究員・ロボット）は複数の謎でヒント役を兼ねられる。
