# 自己レビュー記録

## 2026-09-19 3D脱出ゲーム「LAB ESCAPE」初期実装

### 1. 札の表記が「緑い札」になる
- 対象ファイル: `src/game/game.ts`, `src/ui/ui.ts`
- 問題: 色名に一律で「い札」を付けていたため、緑だけ日本語として誤った表記になった。テストの例が赤だけで、他の色を検証していなかった。
- 修正方針: 色ごとの呼び名 `TAG_LABELS` を持たせた。緑の表記を検証するテストを先に追加し、Redを確認してから修正した。

### 2. 終了画面への切り替えが `status === 'playing'` の分岐内にしかなかった
- 対象ファイル: `src/main.ts`
- 問題: ループ外で状態が `over` になると、終了画面に切り替える処理に到達しない。クリア時は別経路（ドアのコールバック）で切り替えており、終了処理が2系統に分かれていた。
- 修正方針: `ended` フラグを持ち、クリア・時間切れのどちらもメインループ内の1か所で終了画面へ切り替えるようにした。

### 3. 3D表示と謎の文章が矛盾する
- 対象ファイル: `src/scene/room.ts`
- 問題: ホワイトボードの走り書きを青・赤で描いていたが、「赤いペンで書かれている」がヒントになる謎があり、見た目が誤誘導になる。観葉植物も「枯れかけている」というヒントと見た目が合わなかった。
- 修正方針: 走り書きを無彩色にした。植物は該当の謎が出題されたときだけ枯れた色に変える `setPlantWithered` を追加した。

### 4. 通知（トースト）がメモ欄と重なる
- 対象ファイル: `src/ui/style.css`
- 問題: 幅800px程度の画面で、上部中央の通知が右上のメモ欄に重なって読めなかった。
- 修正方針: 通知を画面下側に移した。
